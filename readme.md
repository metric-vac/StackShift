# StackShift

A simple Python tool to edit Minecraft inventories directly from level.dat.

## Features
- View inventory
- Add / remove items
- Change item amounts & slots
- Validate Minecraft item IDs

## Setup
pip install -r requirements.txt

## Run
python main.py
